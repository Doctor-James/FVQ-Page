§2.2 · Finding 2

Bits are the budget for meaning

Raw pixels, continuous features and discrete indices are all finite-bit codes. A discrete token spends B = L · log₂C bits: linear in the number of codebooks L, only logarithmic in codebook size C. So the cheap way to grow the budget is to add codebooks, and understanding climbs as it grows. Until it stops: RVQ and PQ flatten between 112 and 224 bits, because each added codebook gets less to work with.

Finding 2Larger bit budgets raise semantic capacity when the added codes stay informative, far enough for discrete tokens to match continuous ones.

§3 · Method

Factorized Vector Quantization

A quantizer that keeps scaling needs three things. Every codebook plays a symmetric role. Every codebook gets a fixed-dimensional view of the full feature, so adding codebooks never thins out what each one sees. And the views together preserve the feature exactly before quantization. FVQ gets all three from a tight frame: fixed dense projections, parallel nearest-neighbour lookups, and a synthesis operator that inverts the projections.

Analysis · tight frame
ui,ℓ = Rℓzi,   A⊤A = ρID,   ρ = Ld⁄D

L dense projections Rℓ ∈ ℝd×D stacked into A. The tight-frame condition scales every direction equally, so no direction is lost by all views at once. Built once by QR of a fixed Gaussian matrix and never trained.

Symmetric parallel lookup
ki,ℓ = arg minj ‖ui,ℓ − cℓ,j‖²

Each view is matched against its own codebook, independently and in parallel. A patch becomes the tuple (k₁,…,kL) worth B = L log₂C bits, with no residual hierarchy.

Synthesis · exact before quantization
ẑi = 1⁄ρ Σℓ Rℓ⊤cℓ,ki,ℓ

Since ρ⁻¹AᵀA z = z, the factorization adds no error of its own. All distortion comes from snapping views to codewords. After tokenizer training, only the indices go to the VLM, through new embeddings learned from scratch.

§4.4 · Ablations

The bit-budget effect is not a QwenViT quirk

Moving from one VQ codebook (14 bits) to eight FVQ codebooks (112 bits) lifts every encoder tested. Without any industrial-scale data, FVQ trained only on LLaVA-OneVision SFT still beats ViQ, the strongest discrete baseline in that setting.
